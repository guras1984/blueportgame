# BLUEPORT · 아일랜드 트랜스포트

광고와 계정 없이 즐기는 한국어 교통 경영 웹 게임. HTML/CSS/Canvas와 JavaScript 모듈만 사용하며 별도 빌드 단계가 없습니다.

## 플레이
- 철도·버스·트럭으로 출발하고 운송 실적으로 해운·항공을 해금합니다.
- 도시나 산업을 선택해 출발지와 도착지를 연결합니다. 건설 전 비용을 확인할 수 있습니다.
- 원목→제재소→도시, 철광석→제철소→제조소→도시, 곡물→식품공장→도시의 생산망을 구축합니다.
- 차량 추가·성능 개선·교체, 시설 확장, 계약, 대출, 시장 변동을 관리합니다.
- 5단계 회사 목표를 달성한 뒤에도 자유 경영을 계속할 수 있습니다.
- 지도를 드래그하여 이동하고 확대/축소 버튼을 사용합니다. 시간은 정지하거나 1/3/8배속으로 진행할 수 있습니다.
- 같은 브라우저에 자동 저장됩니다. 설정에서 저장 파일을 내보내고 불러올 수 있습니다. 브라우저 데이터를 지우기 전 저장 파일을 내보내세요.

## 로컬 실행
`python3 -m http.server 8795 --directory dist` 실행 후 http://127.0.0.1:8795/ 방문.

## 검증
`node tests/campaign.mjs` — 노선, 생산, 운송, 경제, 5개 교통수단, 최종 목표, 저장 복원.

`node tests/render.test.mjs` — 지형, 선택 표시, 차량 5종, 애니메이션 Canvas 호출 검증.

## 구성
- dist/sim.mjs: 운송·생산·경제 시뮬레이션
- dist/world.mjs: 오리지널 등각 지도와 이동체 렌더링
- dist/app.mjs: 건설·경영·저장 인터페이스

OpenTTD 또는 Transport Tycoon의 코드나 그래픽을 사용하지 않은 독립 게임입니다. 해당 작품 전체의 기능을 재현한 제품은 아닙니다.
